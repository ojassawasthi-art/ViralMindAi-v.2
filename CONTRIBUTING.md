# Contributing to VIRALMIND AI

Thank you for contributing to VIRALMIND AI.

## Guidelines
1. **Evidence & Honesty**: Never add unverified "secret algorithm hack" claims or guaranteed growth promises. Cite official platform documentation when adding platform signals.
2. **Ethical Marketing**: Never introduce dark patterns, fake scarcity, or deceptive persuasion tactics.
3. **Security**: Never commit `.env` files, API keys, or tokens. Keep all provider secrets server-side.
4. **Tests**: Add or update tests in `tests/` and verify `python3 -m unittest discover -s tests -v` passes before opening a PR.
